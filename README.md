# 🎉 微信年度聊天报告生成器

**WeChat Annual Chat Report Generator**

一款基于 Python 的微信聊天记录年度报告生成工具，将聊天数据转化为精美的可视化年度报告。注重情感化表达与用户体验，让数据会讲故事。

## ✨ 项目简介

这不仅是一份数据统计报告，更是一份有温度的年度回忆录。

> "你的消息列表，是一部未完的情感电影"

本项目通过分析微信聊天记录，自动生成包含数据可视化、情感分析、社交画像等多维度内容的交互式HTML报告。每一个统计数字背后，都配有情感化的文案解读，让用户在浏览时能够产生共鸣，回忆这一年与朋友们的点点滴滴。

**一句话介绍**：把你的微信聊天变成一部精美的年度社交纪录片。

## 🎯 项目背景与动机

### 为什么做这个项目？

近年来，各大互联网平台纷纷推出年度报告功能，这类产品在用户群体中广受欢迎，往往能在社交媒体上引发大量自发传播。

微信作为中国最主流的即时通讯工具，承载着用户大量的社交互动数据。然而，微信官方并未提供类似的年度报告功能。用户每天在微信上产生的聊天记录，蕴含着丰富的社交信息和情感价值，却缺乏一种直观、有温度的方式来回顾和展示。

本项目的核心动机是填补这一空白，为用户提供一种将微信聊天数据转化为精美年度报告的工具。我们希望让冰冷的数据变得有温度，让每一条消息背后的故事被看见。

## 🌟 核心特性

### 📊 多维数据分析

本项目对聊天记录进行全方位的统计分析，涵盖以下维度：

**基础统计**：消息总量、字数统计、联系人数量、群聊数量、会话次数等核心指标，让你一眼看清这一年的社交全貌。

**时间维度**：按月份生成聊天热力图，识别消息高峰期和低谷期，发现你的社交节奏规律。24小时圆环热力图展示你的作息特征。

**情感维度**：基于关心问候、深夜陪伴、笑声表情等行为特征，计算聊天的"情感色彩"，用五种颜色描绘你的社交温度。

**关系维度**：分析与每位好友的互动模式，包括消息平衡度、回复速度、会话频率等，生成好友默契度评分。

**健康维度**：全新的社交健康度五维分析，从广度、深度、平衡、关怀、持续五个角度评估你的社交状态。

### 🏅 智能标签系统

**年度称号**：根据聊天行为自动生成个性化称号，如"深夜守望者"、"秒回王者"、"知心大使"等，每个称号都有独特的情感化描述。

**社交人格**：通过四个维度分析你的社交DNA，生成专属人格类型，如"社交蝴蝶"、"深海珍珠"、"月光倾听者"等。

**好友标签**：为每个私聊好友自动生成关系标签，如"秒回达人"、"深夜灵魂伴侣"、"双向奔赴"等，让每段关系都有专属的定义。

**群聊标签**：智能识别群聊类型，自动生成群聊标签。

### 🎨 精美视觉设计

**暗色主题**：采用现代化的深色背景设计，搭配渐变色彩和光晕效果，营造沉浸式的浏览体验。

**动态效果**：星空粒子背景、流星雨动画、开场粒子聚合效果、数字滚动递增、卡片淡入滑动等多种动画效果，让报告充满生命力。

**响应式布局**：完美适配桌面端和移动端，针对不同屏幕尺寸优化布局和交互体验。

### 🔒 隐私保护

提供两种隐私模式供用户选择：

**不脱敏**：保留原始姓名和群名，适合个人收藏。

**脱敏模式**：姓名显示为"*同学"，群名显示为"**群聊"，适合公开分享。

### 📱 便捷分享

**悬浮截图按钮**：高透明度设计不影响视觉，一键截取当前屏幕，截图时自动隐藏。

**长图生成**：支持手机版和PC版两种格式，适合不同分享场景。

**朋友圈九宫格**：自动生成9张方形图片，完美适配朋友圈分享格式。

## 📋 功能模块详解

### 1. 沉浸式开场

展示年度核心数据指标，配有粒子聚合动画和情感化引导文案，为整个报告定下温暖的基调。Canvas实现的光线聚合特效，数字从零滚动递增，打字机效果展示随机励志语录。

### 2. 年度热力图

以12个月为单位的消息分布可视化，直观展示全年的社交节奏。高亮显示消息最多的月份，配有情感化解读。支持悬停查看具体数值。

### 3. 年度旅程时间线

12个月的时间轴展示，每月显示消息数、活跃好友数、聊得最多的人。动态交错淡入动画，让回忆像电影一样徐徐展开。

### 4. 24小时社交节奏

圆环热力图展示24小时消息分布，四时段分析揭示你的作息特征。自动识别最活跃时段并给出情感化解读。

### 5. 年度聊天色彩

基于聊天行为的五维情感色彩分析：

**温暖（粉色）**：你用粉色写下暖暖的回应和抚慰的问候

**陪伴（紫色）**：有话聊到夜深，不愿结束的深度对话

**活力（青色）**：互动频率高，社交广度大

**好奇（黄色）**：提问探索，轻松幽默的氛围

**默契（蓝色）**：对话平衡，双向奔赴的默契

### 6. 表情气质分析

统计Top10常用表情，分析表情使用习惯，判定你的表情气质类型。即使没有表情数据，也会基于聊天行为推断你的表达风格。

### 7. 社交动机分析

五维雷达图展示你的社交驱动力：情感支持、情感共鸣、社交拓展、信息交换、娱乐享受。揭示你打开微信的真正原因，每个维度配有详细解读。

### 8. 社交健康度

给你的社交生活做一次"体检"，五维评分系统：

**🌐 社交广度**：你的社交圈大小

**💎 社交深度**：深度好友数量

**⚖️ 互动平衡**：发送/接收消息的平衡度

**❤️ 情感关怀**：关心与被关心的次数

**📅 联系持续**：长期联系习惯

综合评分0-100，划分为四个等级。

### 9. 好友默契度

五维评分系统，展示与好友的默契程度。从"💎灵魂伴侣"到"🌱默契萌芽"五个等级，高分好友卡片带有光晕特效。

### 10. 好友互动趋势

SVG折线图展示Top5好友的12个月消息变化趋势，每个好友用不同颜色区分。观察谁在你生命中留下了持续的痕迹。

### 11. 私聊排行榜

17+维度排行，好友分组，智能年度洞察。

### 12. 私聊详情卡片

展开查看与每位好友的详细互动数据：消息类型分布、回复速度分析、会话结构、内容丰富度、关怀与邀约统计等。默认只显示前3位好友，点击按钮展开更多。

### 13. 群聊总览

群聊类型智能分类，类型分布统计。分析你的群聊角色。

### 14. 群聊排行榜

群消息排行、个人贡献度分析、群聊作息对比图。包含群聊活力指数和话语权分布分析。

### 15. 群聊详情卡片

每个群的完整档案：群聊类型徽章、活力指数评分条、基础数据网格、话语权分布条形图、智能标签。默认显示前3个群。

### 16. 年度好友荣誉榜

为特别的好友颁发专属荣誉。每个荣誉都配有具体数据和情感化描述。

### 17. 年度数字亮点

大数字冲击力展示页。展示总消息、总字数、好友数、群数、会话数等核心数据，配有趣味换算和阅读时间估算。

### 18. 结语与分享

个性化的年度总结、情感化的感悟语句、新年寄语，以及多种分享功能入口。

## 🛠️ 技术实现

### 技术栈

**数据处理层**

Python 3.8+ 作为主要编程语言，负责数据解析、统计计算和HTML生成。使用 pandas 进行数据处理和分析，statistics 模块进行统计计算，json 和 base64 模块处理数据编码。

**展示层**

HTML5 构建页面结构，CSS3 实现样式和动画，原生 JavaScript 实现交互逻辑和动态效果。Canvas API 实现开场粒子动画，SVG 绘制趋势图和雷达图。html2canvas 库实现截图功能，JSZip 库实现九宫格打包下载。

### 核心算法

**默契度评分算法**

默契度采用五维评分系统，每个维度最高20分，总分100分：

```
总分 = 消息平衡分 + 回复速度分 + 会话频率分 + 深夜陪伴分 + 关心互动分

消息平衡分 = min(双方消息数) / max(双方消息数) × 20
回复速度分 = min(双方回复时间) / max(双方回复时间) × 20
会话频率分 = min(20, 日均会话数 × 10)
深夜陪伴分 = min(20, 深夜消息数 / 5)
关心互动分 = min(20, (关心Ta次数 + Ta关心我次数) / 2)
```

**社交健康度算法**

```
综合得分 = 广度分×15% + 深度分×25% + 平衡分×20% + 关怀分×20% + 持续分×20%

广度分 = min(100, 活跃联系人数 × 2)
深度分 = min(100, 深度好友数 × 10)
平衡分 = min(发送, 接收) / max(发送, 接收) × 100
关怀分 = min(100, 关心次数 / 2)
持续分 = min(100, 长期好友数×3 + 超长期好友数×5)
```

**群聊活力指数算法**

```
活力指数 = 日均消息分(30%) + 成员规模分(25%) + 活跃天数分(25%) + 活跃成员分(20%)

日均消息分 = min(30, 日均消息数 × 3)
成员规模分 = min(25, 成员数 / 4)
活跃天数分 = min(25, 活跃天数 / 15)
活跃成员分 = min(20, 活跃成员数 × 2)
```

**社交人格分析算法**

基于四个维度计算人格特征：

```
主动指数 = 我发起会话数 / (我发起 + Ta发起) × 100%
夜猫指数 = min(100%, 深夜消息总数 / 200 × 100%)
社交广度 = min(100%, 活跃好友数 / 20 × 100%)
表达深度 = min(100%, 平均消息长度 / 50 × 100%)
```

## 🚀 使用指南

### 环境准备

确保系统已安装 Python 3.8 或更高版本：

```bash
python --version
```

安装必要的依赖包：

```bash
pip install -r requirements.txt
```

主要依赖：
- pandas：数据处理
- openpyxl：Excel文件读取

### 数据准备

**支持的数据格式**：

本项目支持两种数据格式：
1. **JSON格式**：推荐格式，处理速度快
2. **Excel格式**：.xlsx 或 .xls 文件

程序会**自动识别**同级目录下的数据文件。

**数据去重**：如果同时存在JSON和Excel文件，程序会自动去除重复的聊天记录。

**JSON数据格式**：

项目提供了 `example/example_data.json` 作为参考示例。

每个聊天对象应包含以下字段：

```json
{
  "name": "好友昵称",
  "type": "private",
  "total_msgs": 1234,
  "their_msgs": 600,
  "my_msgs": 634,
  "monthly": {
    "2025-01": {"total": 100},
    "2025-02": {"total": 150}
  },
  "hours": {"0": 10, "1": 5, "12": 100},
  "sessions": 50,
  "days": 30,
  "late_night": 20,
  "care_them": 10,
  "care_me": 15,
  "reply_them_median": 45,
  "reply_me_median": 60
}
```

**Excel数据格式**：

Excel文件应包含聊天记录的统计数据，具体字段要求与JSON格式类似。

### 运行程序

```bash
python A_report_generator.py
```

按照交互提示完成以下步骤：

1. **输入数据目录路径**：包含聊天数据的文件夹路径
2. **输入你的微信昵称**：用于报告标题和个性化内容
3. **选择隐私脱敏模式**：
   - 不脱敏：保留原始姓名（个人收藏）
   - 脱敏模式：姓名显示为"*同学"（公开分享）
4. **是否分析Excel文件**：如果有Excel文件且数据量大，可选择跳过（Excel处理较慢）

### 输出说明

程序运行完成后，会在**同一目录**下生成HTML报告文件：

```
{你的昵称}的2025微信年度报告.html
```

例如：
- `小明的2025微信年度报告.html`
- `张三的2025微信年度报告.html`

直接用浏览器打开即可浏览。

## 🎨 设计理念

### 情感化表达

本项目的核心理念是"让数据会说话"。每一个统计数字背后，都配有精心设计的情感化文案，将冰冷的数据转化为温暖的故事。

例如，不是简单地显示"深夜消息100条"，而是表达为"100次深夜陪伴，有人愿意陪你熬过那些睡不着的夜"。

### 渐进式叙事

报告采用类似电影叙事的结构，从宏观的年度总览逐步深入到具体的好友互动，像翻阅相册一样引导用户回忆这一年的社交故事。

### 视觉沉浸感

暗色主题搭配粉、青、紫、黄等渐变色彩，配合粒子动画和卡片动效，营造出"星空下回忆往事"的沉浸式氛围。

### 隐私优先

所有数据处理在本地完成，不上传到任何服务器。生成的报告为自包含的HTML文件，可离线浏览和分享。

```css
    --bg3: #1a1a2e;     /* 卡片背景色 */
}
```

```javascript
const slogans = [
```

### 背景音乐

将音乐文件命名为 `bgm.mp3` 放置在数据目录即可自动加载播放。支持MP3格式，建议时长3-5分钟，循环播放。
